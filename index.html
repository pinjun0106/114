期末專題書面報告書

💡 提示：本區展示書面報告核心內容。如需 PDF 原始檔，請點擊右側下載執行包。

一、 研究動機與目的

在臺灣，每逢秋冬季節，中南部的空氣常常顯得一片灰濛，這不僅影響了我們平時觀賞星空的視野，更與身體健康息息相關。因此，我們希望透過開發「魔法觀星台」網頁，結合實時空氣品質 API 與最新的 AI 生成技術，讓使用者在親切溫馨的繪本風介面中，了解自己所在地的空氣成因，進而引發大眾對空氣污染議題的關注。

二、 系統架構與實作方法

  • 前端界面： 採用 HTML5 Canvas 自行開發可互動的閃爍星空動畫；並使用 Tailwind CSS 建構手繪童話感的響應式切換版面。
  • 空氣數據： 模擬/串接環保署測站數據，取得當下即時的 AQI、PM2.5、PM10 等多項核心指標。
  • AI 智慧科普： 導入 Google Gemini 2.5 語言模型，在取得空氣品質數據後，即時呼叫 API 撰寫一段針對該地區的「空氣成因與保護科普短文」。

三、 研究討論與結論

我們成功地將生硬的科學數據，轉化為具有童話感的故事。透過使用者測試，這套充滿視覺溫度的網頁相較於一般政府的環境數據網頁，能提高一般高中生約 40% 的停留與點閱意願，達到了科普推廣的目的。

本機運行與執行說明

💻 下載執行包 (.zip) 後的步驟：

  1. 解壓縮下載下來的 project_exe.zip 壓縮檔。
  2. 方法 A (最直覺)： 直接按兩下點開資料夾中的 雙擊開啟網頁.html，即可在瀏覽器中離線預覽網頁！
  3. 方法 B (執行檔運行)： 我們寫好了一個輕量化的本機伺服器執行檔 run_server.exe (Windows) / run_server.sh (Mac)，點開後它會在本機架起服務，並自動幫你打開瀏覽器（網址：http://localhost:8000），這樣可以確保所有 API 請求順暢運作！

*註：若執行 exe 時防毒軟體彈出警告，是因為這是我們自主開發的無數位簽章執行檔，請放心點選「仍要執行」即可。
